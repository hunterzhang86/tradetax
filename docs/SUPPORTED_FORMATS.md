# 支持的账单格式

解析器对表头采用模糊匹配(关键词命中), 对列顺序、中英文命名、币种符号有较强容错。以下是已实现与已核验的格式。

## 富途牛牛 / moomoo

- **文件**: `XXXX_年度账单_XXXXXXXX.xlsx`
- **获取**: 富途牛牛 APP → 账户 → 更多 → 我的税表 → 年度账单 → 下载
- **工作表**: 账户信息 / 证券-持仓总览 / 证券-交易流水 / 证券-资金进出(工作表名前缀不影响识别)
- **股息提取**: 从「资金进出」的备注识别, 支持英文格式(`AAPL 100 SHARES DIVIDENDS ... PER SHARE`)与标记(`F/D` 现金分红、`S/D` 股票分红、`W/TAX` / `股息税` / `预扣税`)
- **状态**: ✅ 已核验(表结构来自多个开源解析器与测试数据)

## 老虎国际 (Tiger Brokers)

- **文件**: Activity Statement CSV(需勾选「显示详细交易记录」)
- **获取**: 老虎国际 APP → 老虎账户 → 账单报表 → 自定义 → 选择日期范围 → CSV 格式
- **结构**: 元数据行 + 分区块(`Trades` / `Dividends` 各带独立表头), 固定列索引, 交易时间为多行引号字段
- **费用**: 自动汇总全部费用列(佣金 / 印花税 / 平台费 / 结算费 / 监管费 ...)
- **方向**: 由 Activity Type(`Open`=买入 / `Close`=卖出)与数量符号共同确定
- **股息**: ✅ 交易区块已核验; ⚠️ 股息区块为尽力解析(未获得真实股息样本, 预扣税按费用列绝对值估算)
- **注意**: 若你的导出是中文版或不同区块命名, 解析器会给出告警而非静默丢弃

## 长桥 (Longbridge)

- **文件**: 交易记录 CSV
- **推荐格式** (官方模板): `type,date,symbol,market,side,quantity,price,fees,currency,source_country,gross_amount,withholding_tax`
  - `type` = `trade` / `dividend`, 股息行使用 `gross_amount` 与 `withholding_tax`
  - 金额缺失时按 `数量 × 价格` 兜底计算
- **兼容**: 中文表头(业务时间 / 股票代码 / 账户流向 / 业务分类等)同样支持
- **状态**: ⚠️ 部分核验——CSV 模板来自官方文档; 若你的导出列名不同, 请按下方反馈

## 尚未支持

- 长桥「月结单」XLSX(股票台账格式缺少成交价格与金额列, 无法计算盈亏, 请使用交易记录 CSV)
- 老虎 / 长桥的历史 PDF 月结单
- 富途利息股息汇总 xlsx(仅作核对, 非必需)

## 反馈样本

如果你的账单无法被正确解析, 欢迎提供**脱敏后的样本**(删除账户号、姓名等敏感信息)帮助完善解析器。需包含: 文件类型、导出路径、表头行、2-3 行示例数据。
